# IT-Support-Home-Lab
I created this home lab to practice common IT support tasks, focusing on user account management, access, and troubleshooting.

The lab uses Windows Server 2022, Active Directory, a Windows client machine, Microsoft Entra ID, and ServiceNow. I use it to practice situations I could encounter in a help desk or IT support role, from creating a new employee account to troubleshooting a locked user account.

## What I Practiced

- Creating and managing Active Directory users
- Organizing users with Organizational Units (OUs)
- Creating and managing security groups
- Adding and removing users from groups
- Resetting user passwords
- Unlocking locked Active Directory accounts
- Disabling and enabling user accounts
- Testing user sign-ins from a Windows client
- New employee onboarding
- Employee offboarding
- Managing users and groups in Microsoft Entra ID
- Creating, updating, documenting, and resolving ServiceNow tickets

## Lab Environment

- Windows Server 2022
- Active Directory Domain Services
- Windows 11 Client
- Microsoft Entra ID
- ServiceNow
- VMware

## Projects

### 1. Active Directory Environment Setup
Built an Active Directory lab environment with users, groups, Organizational Units, and a domain-joined Windows client.

### 2. New Employee Onboarding
Created a new employee account in Active Directory, assigned the appropriate group access, verified the account, tested the user's sign-in, and documented the completed work in ServiceNow.

### 3. Account Lockout Troubleshooting
Reproduced a locked-account issue from the Windows client, identified the locked account in Active Directory, unlocked it, verified that the user could sign in again, and documented the resolution in ServiceNow.

### 4. User Access and Group Management
Practiced adding and removing users from security groups and verifying group membership to manage access.

### 5. Employee Offboarding
Practiced disabling user accounts and removing access as part of an employee offboarding scenario.

### 6. Microsoft Entra ID
Practiced cloud identity administration, including user and group management in Microsoft Entra ID.

## Purpose Of The Lab

I built this lab to strengthen my hands-on IT support skills and gain experience working through realistic user account and access scenarios. My long-term goal is to continue developing my skills in identity and access management.

# New Employee Onboarding

## Overview

In this project, I practiced a new employee onboarding scenario using Active Directory and ServiceNow. The goal was to simulate the account setup and access management tasks that an IT support technician may complete when a new employee joins an organization.

## Scenario

A new employee required an Active Directory account and access to the appropriate resources based on their role.

I created the employee's account, assigned the appropriate group membership, verified the account configuration, tested the user's ability to sign in, and documented the completed work in ServiceNow.

## Tasks Completed

- Created a new user account in Active Directory
- Configured the user's account information
- Assigned the user to the appropriate security group
- Verified group membership and access
- Tested the user's domain sign-in from the Windows client
- Documented the onboarding request in ServiceNow
- Updated and resolved the ServiceNow ticket after verifying the account

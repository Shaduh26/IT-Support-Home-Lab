# Active Directory Environment Setup

## Overview

I built an Active Directory home lab to practice user account administration and common IT support tasks in a Windows domain environment.

The environment includes Windows Server 2022 as the domain controller and a Windows 10 client joined to the domain. I used the lab to practice managing users, groups, Organizational Units (OUs), and user access.

## Lab Environment

- Windows Server 2022
- Active Directory Domain Services (AD DS)
- Windows 10 Client
- VMware

## What I Configured

- Created Organizational Units (OUs) to organize users and computers
- Created Active Directory user accounts
- Created and managed security groups
- Added users to appropriate groups
- Joined a Windows 10 client to the domain
- Tested domain user sign-ins from the client machine

## Skills Practiced

- Active Directory administration
- User and group management
- Organizational Unit management
- Security group membership
- Domain-joined client management
- Basic identity and access management

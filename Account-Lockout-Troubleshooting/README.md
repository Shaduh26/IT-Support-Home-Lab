# Account Lockout Troubleshooting

## Overview

In this project, I practiced troubleshooting a locked Active Directory user account in a Windows domain environment. The goal was to simulate a common IT support scenario where a user is unable to sign in because their account has been locked.

I used Active Directory Users and Computers to investigate the account, restore access, verify that the user could successfully sign in, and document the troubleshooting process in ServiceNow.

## Scenario

A user contacted the IT Service Desk because they were unable to sign in to their Windows account.

I investigated the user's Active Directory account, identified the account lockout, restored access, tested the user's login from the Windows client, and documented the resolution in ServiceNow.

## Tasks Completed

- Reviewed the user's ServiceNow support ticket
- Located the user account in Active Directory
- Identified that the account was locked
- Unlocked the user's Active Directory account
- Reset the user's password when required
- Tested the user's domain sign-in from the Windows client
- Verified that account access was restored
- Documented the troubleshooting steps and resolution in ServiceNow
- Resolved the support ticket after verification
